# VAPT Home Lab – Kali Linux & Metasploitable 2

## Project Overview

This repository documents my practical learning journey in Vulnerability Assessment and Penetration Testing (VAPT).

The lab environment is built on an Apple MacBook M4 using UTM virtualization, Kali Linux ARM64 as the attacker machine, and Metasploitable 2 as the intentionally vulnerable target.

### Objectives
- Understand network reconnaissance and discovery.
- Perform TCP port scanning using Nmap.
- Identify running services and software versions.
- Research potential vulnerabilities using SearchSploit.
- Integrate Nmap scan results with Metasploit.
- Perform controlled vulnerability validation.
- Document security findings and remediation recommendations.

### Lab Environment
- Host: Apple MacBook M4
- Virtualization: UTM
- Attacker: Kali Linux ARM64
- Target: Metasploitable 2
- Database: PostgreSQL
- Scanning: Nmap
- Security Framework: Metasploit
- Vulnerability Research: SearchSploit

### Disclaimer
This project is intended for educational purposes and authorized security testing only. All testing is performed within an isolated virtual lab environment.
